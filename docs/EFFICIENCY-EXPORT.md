# 패효율 연습 기록 내보내기

패효율 화면의 **기록 내보내기**를 누르면 현재 연습의 보고서를 확인할 수 있습니다. 타패 전, 다음 쯔모를 기다리는 동안, 텐파이 결과 화면에서 모두 사용할 수 있습니다.

- **보고서 복사**: 다른 문서나 분석 도구에 붙여넣습니다. 클립보드가 차단되면 본문이 선택되므로 직접 복사하거나 파일로 저장할 수 있습니다.
- **텍스트 저장 (.txt)**: 일반 텍스트 편집기에서 읽을 수 있습니다.
- **Markdown 저장 (.md)**: 제목과 목록을 지원하는 편집기에서 구조적으로 읽을 수 있습니다.

두 파일과 클립보드는 동일한 UTF-8 본문을 사용합니다. 파일명은 `riichi-efficiency-<UTC 내보낸 시각>.txt` 또는 `.md`입니다. 형식 식별자는 `riichi-efficiency-report v1`입니다. 외부 분석용 문서이며 앱에서 불러오는 기능은 없습니다.

## 보고서 순서

1. **연습 요약**: 진행 상태, 타패 횟수, 누적 점수/최대 점수, 비율, 최적 선택 횟수, 최초·현재/최종 손패, 시간순 버림패.
2. **계산 기준과 읽는 법**: 채점 방법, 미확인 매수의 의미, 기호 표기, 평가 범위.
3. **최종 구조적 대기**: 텐파이 종료 시 대기별 종류·형태·미확인 장수와 합계. 0장인 구조적 대기도 남깁니다.
4. **개선할 수 있었던 선택**: 비최적 선택의 순목·타패·이유.
5. **타패별 상세 기록**: 타패 전후 손패, 쯔모패, 실제 타패, 샨텐, 유효패별 매수, 모든 공동 최적 후보, 손실, 순별·누적 점수, 당시 확인된 매수, 모든 후보의 비교.

패는 `적5만`, `동`처럼 한글로 표시하고, 손패에는 `123m456p789s1122z` 형태의 기호도 병기합니다. 적5는 `0`으로 기록합니다. 실제 버린 물리 패를 보존하지만 패효율 후보는 적5와 일반5를 같은 종류로 비교합니다.

## 분석 기준

일반형·치또이츠·국사 중 가장 낮은 샨텐을 먼저 비교하고, 같은 샨텐에서 유효패 장수가 가장 많은 모든 후보를 최적으로 인정합니다. 매 순의 최대 점수는 당시 최적 후보의 유효패 수(0장이면 1점)입니다. 누적 분모는 실제 진행한 순들의 최대 점수 합이며, 다른 경로로 연습했을 때의 전역 최대 점수를 뜻하지 않습니다.

기록 당시 저장된 손패·이전 버림패의 공개 매수와 후보 평가를 그대로 내보냅니다. 뒤에 뽑은 패로 과거 선택을 재평가하지 않습니다. 미래 패산과 시드는 읽거나 내보내지 않습니다. 미확인 매수는 실제 패산의 구성이나 화료 확률과 다릅니다.

보고서는 기존 1회 쯔모 기준 점수만 담습니다. 선택적으로 계산하는 2회 쯔모 분석, 역·타점·후리텐·상대 수비는 이 점수에 포함되지 않습니다. 최종 대기는 구조적 완성 대기이며 실제 론/쯔모의 합법성을 보장하지 않습니다.

내보내기는 연습 상태를 변경하지 않습니다. 미리보기 이후 타패하거나 쯔모하면 오래된 미리보기가 닫힙니다. 다시 내보내면 갱신된 기록을 얻습니다. 새 연습을 시작하거나 페이지를 새로 열기 전에 필요한 기록을 저장하세요.

## 테스트

`tests/efficiency-report.test.js`는 기록 순서·당시 정보 보존, 공동 최적 선택, 샨텐 손실, 적패, 세 종류 텐파이 대기, 숨겨진 패산 미참조와 상태 불변성을 검사합니다.

`tests/browser-efficiency-export.mjs`는 기존 브라우저 통합 테스트에서 호출합니다. 실제 미리보기와 두 다운로드 파일의 UTF-8 내용, 클립보드 성공/실패, 상태 보존, 모바일 영역 경계를 검증합니다. 진행 중·완료·새 연습을 통한 갱신 흐름도 검사합니다.
